# FRONT-END-PROJECT
# Hot Zone – Food Website

Hot Zone is a simple food website built with HTML and Tailwind CSS. It showcases different food categories and provides links to individual pages.

## Features

- Responsive layout styled with Tailwind CSS
- Home page and food category pages
- Navigation to pages such as burgers, pizza, momos, sandwiches, shawarma, and ice cream
- About and customer pages

## Technologies Used

- HTML5
- Tailwind CSS (loaded through its CDN)

## Run Locally

1. Clone or download this repository.
2. Open the `Front_End` folder.
3. Open `index.html` in your browser.

An internet connection is needed for Tailwind CSS CDN styles and any externally hosted images.

## GitHub Pages Deployment

If deploying with GitHub Pages, ensure the published directory contains an `index.html` file. The standard branch-based GitHub Pages setting supports the repository root or `/docs`; to publish the `Front_End` folder, move the website files to the repository root or configure a GitHub Actions workflow to publish that folder.
